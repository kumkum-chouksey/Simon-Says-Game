# 🎮 Simon Says Game

A simple memory game built using HTML, CSS, and JavaScript where players repeat an increasing sequence of colors.

## 🚀 Features
- 4 colored boxes with flash effect
- Random sequence generation
- Level increases with each correct step
- Game over on wrong input
- Restart option

## 🕹️ How to Play
1. Start the game.
2. Watch the flashing color sequence.
3. Click the colors in the same order.
4. Sequence grows each level.
5. Wrong click = Game Over.

## 🛠️ Tech Stack
HTML, CSS, JavaScript

## 📂 Files
- index.html  
- style.css  
- script.js

## 📚 Concepts Used
DOM manipulation, event handling, arrays, setTimeout
